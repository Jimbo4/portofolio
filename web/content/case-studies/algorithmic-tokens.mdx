## Code as a collectible

2022 was the year of the metaverse. Brands bought land in virtual worlds, NFT marketplaces traded billions and every company was looking for its way into Web3. The AI consultancy I worked at wanted one too, in a form that said something about its own craft.

Algorithmic Tokens is a collection of non-fungible tokens on Ethereum, one for each famous algorithm, from Hello, World! to the neural networks behind modern computer vision. Nobody draws the tokens by hand: a script reads the source code of each algorithm and derives the image from it, so every token is a portrait of its code.

## A collection for an AI company

The project was a business experiment and a way to show what the company knew best. It had to:

- **Enter the Web3 conversation** while NFTs and the metaverse were at their peak, with a collection the company owned and could show.
- **Show the craft** by putting AlexNet, GoogleNet, ResNet and AdaBoost, models the team worked with every day, next to the classics every developer knows.
- **Let the code draw itself**: the same code always gives the same token, with no hand-made choices in between.
- **Live on chain**: minted on Ethereum and traded on OpenSea, with a creator fee on every resale.
- **Take part in the Metaverse Summit** in Milan in 2022 with a real project to show and talk about.

## How a token is drawn

The generator turns three properties of the code into three visual rules. Together they make every token unique and repeatable: anyone who runs the same code through the generator gets the same image.

<Figure src="/images/case-studies/algorithmic-tokens/anatomy.webp" alt="The AdaBoost token, large, with an 80-column ruler above its bars, a brace along the ten bars, and three numbered notes: length on a log scale, width in 80 columns, and the color #6d13e6 from the keccak256 hash of the code" width="1800" height="1013" caption="AdaBoost, read through the three rules." />

<Principles>
  <Principle label="Length">
    The number of bars follows the length of the code on a logarithmic scale, so a one-liner and a neural network fit in the same frame.
  </Principle>
  <Principle label="Width">
    Each bar is measured against the 80 characters per line that most style guides recommend: a bar across the whole token is a full line.
  </Principle>
  <Principle label="Color">
    The color is the first six hex digits of the keccak256 hash of the code, the hash function Ethereum itself relies on. Change one character and the color changes.
  </Principle>
</Principles>

## From script to OpenSea

I took the project from the idea to the marketplace, writing the code at every step.

<Steps>
  <Step label="Pick the algorithms">
    I chose a first set that goes from the first program anyone writes to the models the company worked with, in Python, Java and JavaScript.
  </Step>
  <Step label="Write the generator">
    A Python script reads each source file, measures its length and its lines, hashes it with keccak256 and draws the token as a square image.
  </Step>
  <Step label="Prototype the contract">
    I wrote a custom ERC-1155 contract in Solidity to mint the tokens with their metadata, and deployed it on an Ethereum testnet to try the whole minting flow.
  </Step>
  <Step label="Publish on OpenSea">
    For the public release I moved the collection to OpenSea's shared storefront on Ethereum, with a name and description for every token, the collection page and a 3% creator fee.
  </Step>
  <Step label="Bring it to the summit">
    The collection gave the company a concrete Web3 project to bring to the Metaverse Summit in Milan in 2022.
  </Step>
</Steps>

## Seven tokens on chain

Algorithmic Tokens lives on Ethereum as a collection of seven unique tokens, each one generated from the code it represents. The same generator can turn any other algorithm into a new token with the same rules, so the collection can grow one algorithm at a time.
